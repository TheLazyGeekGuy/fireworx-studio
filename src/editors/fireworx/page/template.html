MATRICE DE CONTRÔLE · MANUEL P. 30–38

Relier un geste à un paramètre

Une seule source par destination, vingt liens au maximum. Les liens ci-dessous sont des intentions locales ; aucun octet MIDI n’est déduit.

Deux réseaux différents

Le routage transporte l’audio. La matrice transporte des valeurs de contrôle, de 0 à 100, converties dans le domaine du paramètre.

Chaque lien peut transformer Low, Mid, High, Slope et Glide Time. Ces transformations sont recensées ; leur édition n’est pas encore reproduite ici.

Un paramètre relié conserve sa valeur de rappel, puis le modulateur prend la main. Un générateur Synth produit de l’audio ; un LFO produit du contrôle.

La matrice matérielle peut aussi piloter d’autres modulateurs, sans auto-modulation. Ce prototype couvre seulement les destinations d’effets marquées d’un astérisque.

SW 2.00 ET ULTÉRIEUR

Préparer une lecture du buffer

Le message 45 demande un preset au format étendu. Le preset 0 désigne le buffer d’édition. Cette action prépare les octets ; elle ne les transmet pas.

Aucune requête préparée

Réponse attendue : 20 (données étendues) ou 28 (emplacement vide). Aucun délai de réponse ni ACK d’écriture n’est spécifié.

Inspecter une réponse .syx

Une seule trame brute. L’outil vérifie en-tête, Device ID, longueur, demi-octets et checksum. Le contenu reste opaque.
